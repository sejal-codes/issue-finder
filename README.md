# 🔍 Unassigned Issue Finder

> **Find open-source issues you can actually contribute to — without wasting hours scrolling through claimed, stale, or abandoned tickets.**

**Unassigned Issue Finder** is a full-stack web application that searches the **GitHub Search API** to help developers discover **open, unassigned, beginner-friendly issues**.

Filter issues by **labels, programming language, recency, and repository popularity** — so you spend less time hunting for issues and more time actually contributing.

## ✨ Why This Exists

Finding a good first issue on GitHub often means:

- 🔎 Opening **15+ repositories** just to find one suitable issue
- ❌ Discovering that someone already claimed it **three weeks ago**
- 💤 Finding out the repository hasn't been maintained **since 2022**
- 🏷️ Realizing that the `good first issue` label isn't actually beginner-friendly

**Unassigned Issue Finder cuts through that noise.**

It queries GitHub's Search API directly and helps surface issues that are:

- ✅ **Open**
- 👤 **Unassigned**
- 🏷️ **Beginner / contributor friendly**
- 📅 **Recently created**
- ⭐ From repositories meeting your minimum star requirement
- 💻 Relevant to your preferred programming language
